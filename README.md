# 🍅 AI 自适应番茄钟任务管理系统 v2.0

## 项目简介
一款基于 C++ 的轻量化命令行个人效率管理系统，在传统番茄工作法基础上，创新性地引入 **AI 自适应专注调节** 与 **专注状态反馈机制**，让番茄钟时长不再固定，而是根据你的实时专注状态动态调整。

> **与普通番茄钟的最大区别**：系统不再机械地固定 25 分钟，而是专注过程中主动询问你的专注状态，据此实时延长或缩短本轮，并"学习"你的专注节奏，给出个性化推荐时长。

## 核心功能

### 1. 任务管理
- 智能添加：自然语言输入（如"明天完成高数作业，优先级高，预计2个番茄"），自动解析优先级、预计时长、截止日期
- 手动添加：自定义任务名称、优先级、预估番茄数
- 查看 / 标记完成 / 删除

### 2. AI 自适应番茄钟（创新点）
- **专注反馈系统**：计时中每 N 分钟（可在菜单 9 设置）主动询问：
  ```
  [专注度反馈] 现在感觉怎么样？
  1. 非常专注  2. 状态一般  3. 容易分心
  ```
- **实时自适应调时**：
  - 非常专注 → 本轮**自动延长 5 分钟**
  - 状态一般 → 保持节奏
  - 容易分心 → **提前结束本轮**，进入休息
- **个性化推荐**：基于历史实际专注时长，自动推荐下次的专注时长（菜单 4）
- **专注度量化**：记录本轮反馈分布，计算综合专注度

### 3. 数据持久化与统计
- `tasks.txt`：任务数据（逗号分隔）
- `pomodoro_log.txt`：专注会话日志（记录开始/结束时间、计划/实际时长、反馈等级、是否提前结束）
- **专注画像**（菜单 8）：总专注次数、累计时长、综合专注度、提前结束率、平均每次专注
- **时间利用分布**（菜单 8）：一天中专注时段分布，找出你最专注的时段

### 4. 彩色动态界面
- 用 ANSI 颜色区分专注（绿）/ 休息（青）/ 反馈（黄）/ 提前结束（红）等状态

## 技术架构
| 模块 | 文件 |
|------|------|
| 主程序、菜单、反馈循环 | `main.cpp` |
| 任务管理（Task / TaskManager） | `task_manager.h` / `.cpp` |
| 番茄钟计时（多线程 + 反馈自适应） | `pomodoro_timer.h` / `.cpp` |
| 数据存储、统计、画像、NLP 解析 | `data_storage.h` / `.cpp` |
| 数据文件 | `tasks.txt` / `pomodoro_log.txt` |

- **开发语言**：C++17
- **并发**：`std::thread` + `std::atomic<bool>` + `std::mutex`（倒计时在独立线程，主线程不卡顿）
- **跨平台**：Windows / Linux / macOS

## 编译运行

### Windows (MinGW / MSYS2)
```bash
g++ -std=c++17 -finput-charset=utf-8 -fexec-charset=utf-8 -o pomodoro.exe \
    main.cpp task_manager.cpp pomodoro_timer.cpp data_storage.cpp
./pomodoro.exe
```

### Linux / macOS
```bash
g++ -std=c++17 -o pomodoro main.cpp task_manager.cpp pomodoro_timer.cpp data_storage.cpp
./pomodoro
```

> 提示：首个字符若为中文乱码，请确保终端为 UTF-8 编码（Windows 下程序会自动 `chcp 65001`）。

## 使用说明
启动后主菜单（1-10）：
```
1. 查看所有任务      2. 智能添加任务      3. 手动添加任务
4. 开始番茄钟        5. 标记任务完成      6. 删除任务
7. 查看统计信息      8. 专注画像/时间分布
9. 设置反馈间隔      10. 保存并退出
```
- 使用「AI 自适应」功能前，请先在菜单 9 设置反馈间隔（如 10 分钟），否则反馈系统不触发。
- 菜单 8 需要先有专注记录（新格式）才会显示画像数据。
